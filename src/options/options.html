Quick Asana task

Creates an Asana task from the current page with one keyboard shortcut. Claude drafts the title and a one-line summary through the Anthropic API, and the task is created through the Asana API. Assign the shortcut at chrome://extensions/shortcuts ("Create an Asana task from this page"). Keys are stored only in this browser and are sent only to Asana and Anthropic.

Create one in the Asana developer console (app.asana.com/0/my-apps).

Tasks are only ever created in this workspace.

New tasks are filed in this section of your My Tasks.

Use the local helper if your Anthropic organization doesn't allow requests from a browser, or to keep the key out of the browser. It needs a one-time install: see helper/README.md in the Precog repository.

From console.anthropic.com. Each task costs a small amount of API usage.

Claude follows this when drafting the task. To have a project or custom fields set, list the project names and the custom field and option IDs here.
